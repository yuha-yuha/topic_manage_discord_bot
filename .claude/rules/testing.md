# テストの規約

- テストファイルは対象と同じディレクトリに `xxx_test.go` として置く。
- 複数ケースはテーブル駆動テストで書き、各ケースは `t.Run` でサブテストにする。
- ヘルパー関数では `t.Helper()` を呼ぶ。
- `handler` のテストは `net/http/httptest` を使う。
- `service` のテストでは repository をインターフェース経由でフェイクに差し替える。
- 並行実行して問題ないテストは `t.Parallel()` を付ける。
- 外部リソース（DB など）に依存するテストは、通常のユニットテストと区別できるようにする（build tag や `testing.Short()` など）。
